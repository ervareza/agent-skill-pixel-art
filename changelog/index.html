Changelog

v1.0.0 2026-11-26

Added

  • Pure-Python PixelForge Engine (skills/pixel-art/engine/) — Ground-up modular pixel art engine (color.py, canvas.py, character.py, tileset.py, vfx.py, assets.py, exporters.py, qa.py) synthesized from 17 top-starred open-source pixel art skills and studios.
  • True 15-Layer Character Rig & Paper-Doll System — Dedicated bottom-to-top layers (shadow, cape_back, hair_back, arm_far, leg_far, torso, leg_near, head, hair_front, headgear, arm_near, weapon, shield, vfx, outline) with blend modes, opacity, linked cels, and per-layer PNG sheet export.
  • True 1/2/4/8-Direction Walk & Combat Animator — Shared landmark rows across all directions (zero turning bob), North view with zero face, darker far limbs, 8 actions (idle, walk, run, jump, attack, cast, hurt, die), 9 archetypes (hero, knight, mage, ranger, rogue, villager, skeleton, goblin, slime).
  • Arbitrary Pixel Resolutions & Arbitrary Frame Counts — Resolution-tier-aware proportions supporting 8×8, 9×9, 12×12, 16×16, 16×24, 24×24, 32×32, 48×48, 64×64, 128×128+ and continuous-phase sampling for 2, 3, 4, 5, 6, 8, 12, 24, 60 frames (1–60 FPS).
  • Seamless Toroidal Terrain & Autotile Generator — 11 terrain presets, 16-tile Wang & 47-tile Blob autotiles, animated water/lava loops, and 2:1 isometric blocks.
  • 12 Seeded Procedural Pixel VFX — explosion, fire, smoke, slash, sparkle, magic_orb, lightning, water_splash, heal_aura, hit_impact, portal, coin_spin.
  • Game Items, ZzSprite Creatures, 9-Slice UI & Fake-3D Sprite Stacking — 10 RPG items/weapons, symmetrical procedural creature generator, 5 UI components, and 360° fake-3D stacked slice turntables.
  • Native Binary .aseprite Writer & Universal Engine Exporters — Exports valid Aseprite v1.3 files with layers/tags/palette, Godot 4 .tres SpriteFrames, Aseprite/Phaser/Unity JSON, RPG Maker 3×4, LPC 64×64, transparent GIFs, and alpha-preserving indexed PNGs.
  • 8 New CLI Scripts & 6 New Palettes — 21 total CLI scripts (including pixel_studio.py, character_gen.py, layer_compose.py, tileset_gen.py, vfx_gen.py, asset_gen.py, sprite_stack.py, sprite_clean.py) and 16 curated palettes (added aap-64, lospec-500, fantasy-24, cyberpunk-16, pastel-16, onebit).
  • Interactive Playable 4-Dir Walk Arena & /changelog Page — Live WASD/D-pad layered character sandbox on index.html, upgraded HTML5 templates (including turntable_viewer.html), and 67-test pytest suite.

Changed

  • Complete ground-up v1.0.0 reboot on a unified main branch, replacing legacy placeholder examples with verified, game-ready multi-layer assets.
  • Upgraded SKILL.md and expanded reference knowledge base to 10 guides (added layering_and_rigging.md, sprite_stacking.md, critique_and_qa.md).

Fixed

  • export_indexed.py no longer destroys alpha transparency into solid black when quantizing RGBA PNGs to 8-bit indexed mode.
  • outline_generator.py now properly implements --inset plus new --mode selout and --rim-light passes.
  • noise_generator.py now uses true 4-edge toroidal wrapping so generated terrain tiles have zero visible seams.
  • quality_audit.py defaults to --grid 1 so odd/non-power-of-two resolutions like 9×9 and 12×12 audit cleanly, and adds jaggies/doubles, clipping, palette conformance, and seamlessness checks.
