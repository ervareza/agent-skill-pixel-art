Core Engine Utilities

Five high-performance Python modules designed for modular asset synthesis

🏗️

Forge Workspace

Initializes standardized project folder structures, imports reference media, and validates contract locks.

🎨

Chroma Analyzer

Extracts dominant palettes using Euclidean distance clustering ($\Delta E_{RGB}$) and enforces color budgets.

🔍

Asset Inspector

Scans asset PNGs for canvas boundary multiples, semi-transparent pixels, and palette breaches.

📦

Atlas Packer

Packs individual PNG frames into 2D sprite sheets paired with structured JSON metadata manifests.

🧹

Post-Processor

Executes palette quantization, 4-neighborhood stray orphan pixel removal, and 8-bit indexed PNG conversion.
