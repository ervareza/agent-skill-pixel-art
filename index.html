Autonomous 2D Pixel Art & Raster Matrix Engine

Decoupled raster compiler engineering for Claude Code, OpenAI Codex, and Antigravity IDE. Zero anti-aliasing artifacts, hardware LumaLUT enforcement, and structured texture atlases.

⚡ CanvasBootstrapper

Automates voxel canvas node creation and asset contract manifests.

python3 RenderOrchestrators/CanvasBootstrapper.py --grid-matrix standard_sprite_32

🎨 ChromaSynthesizer

Extracts colors, computes 3D RGB distance metrics, and maps to target LumaLUTs.

python3 RenderOrchestrators/ChromaSynthesizer.py --image raw.png

🔍 QualitySentinel

Performs quality audits, verifying grid alignment, AA artifacts, and orphan pixels.

python3 RenderOrchestrators/QualitySentinel.py --image sprite.png

📦 AtlasSynthesizer

Packs sprite animation frames into texture atlases with JSON metadata manifests.

python3 RenderOrchestrators/AtlasSynthesizer.py --frames-dir ./frames/
