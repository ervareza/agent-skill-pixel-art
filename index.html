Autonomous 2D Pixel Art & Raster Matrix Engine

Decoupled raster compiler engineering for Claude Code, OpenAI Codex, and Antigravity IDE. Zero anti-aliasing artifacts, hardware LUT enforcement, and structured texture atlases.

⚡ MatrixCanvasInitializer

Automates workspace directory creation and asset contract specification manifests.

python3 scripts/canvas_initializer.py --preset standard_sprite_32

🎨 PaletteLUTSynthesizer

Extracts colors, computes 3D RGB distance metrics, and maps to target hardware LUTs.

python3 scripts/lut_synthesizer.py --image raw.png

🔍 RasterSpecInspector

Performs quality control inspections, verifying grid alignment, AA artifacts, and orphan pixels.

python3 scripts/spec_inspector.py --image sprite.png

📦 SpriteAtlasCompiler

Packs multiple sprite animation frames into texture atlases with JSON metadata manifests.

python3 scripts/atlas_compiler.py --frames-dir ./frames/

Engine Changelog

Release notes and version history for PixelMatrix Engine.

[v2.0.0] - 2026-07-22

MAJOR RELEASE — Total Architecture Purge, Rebrand & Expansion

  • Rebranded Engine: Transformed from legacy state into PixelMatrix Engine (v2.0.0).
  • Complete Legacy Purge: Removed old scripts, legacy paths, and obsolete terminology.
  • New Compiler Modules: Built MatrixCanvasInitializer, PaletteLUTSynthesizer, RasterSpecInspector, SpriteAtlasCompiler, and PixelRasterPostProcessor.
  • Extended Content Specs: Expanded grid presets (16x16 to 256x256), isometric (48x48) autotiling, 4/8-way directional character matrices, HUD 9-slice elements, and 8+ Palette LUTs.
  • Multi-Agent Integration: Full instructions for Claude Code, OpenAI Codex, and Antigravity IDE.
